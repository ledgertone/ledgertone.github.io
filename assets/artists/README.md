# Artist images

Local files only, referenced from `data/snapshots.js` with `image: "assets/artists/<file>"` (png, jpg, webp, or svg). Never hotlink images from Pandora or any other host: the site makes no external requests.

The current SVG files are generated placeholders for the fictional sample artists. Replace them with real images the owner has the right to use, and delete the placeholders before launch.
