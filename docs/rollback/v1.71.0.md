Owner decisions of 2026-11-01: no violet anywhere, the red pill is changed, the glass stays. Changed: `assets/styles.css`, the wording of `AGENTS.md` (rule 11, Design rules Color, rule 30 item 4) and the version stamps.

## How to go back
- Whole files: copy `docs/rollback/styles.css.v1.70.0` over `assets/styles.css` and `docs/rollback/AGENTS.md.v1.70.0` over `AGENTS.md` (the exact v1.70.0 files).
- By patch: in the site folder run `patch -R assets/styles.css < docs/rollback/v1.71.0-styles.css.patch` and `patch -R AGENTS.md < docs/rollback/v1.71.0-AGENTS.md.patch`.
- Further back: `docs/rollback/v1.70.0.md` and `styles.css.v1.69.0`.
- After any rollback raise the version, update `CHANGELOG.md` and `TODO.md`, run `node scripts/check-release.js`.
