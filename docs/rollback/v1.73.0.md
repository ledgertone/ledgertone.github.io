## How to go back
- Image: copy `docs/rollback/og-image.png.v1.72.0` over `assets/og-image.png`. It is a binary file, so there is no patch.
- Version stamps: not needed for a visual rollback; after any rollback raise the version, update `CHANGELOG.md` and `TODO.md`, run `node scripts/build-all.js` and `node scripts/check-release.js`.
