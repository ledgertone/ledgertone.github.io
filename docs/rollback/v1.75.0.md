# Rollback of v1.75.0

No github.io anywhere (owner decision, new rule 31), links without the browser blue, unused staff CSS removed. Changed: `assets/styles.css`, `assets/og-image.png`, `AGENTS.md`, `CLAUDE.md`, `README.md`, `scripts/check-release.js`, `CHANGELOG.md`, `TODO.md`, `docs/rollback/v1.73.0.md` (text only), version stamps.

## How to go back
- Whole files: copy `docs/rollback/<file>.v1.74.0` over the file: `styles.css` (to `assets/`), `og-image.png` (to `assets/`), `AGENTS.md`, `CLAUDE.md`, `README.md`, `check-release.js` (to `scripts/`).
- By patch (not for the PNG): in the site folder run `patch -R assets/styles.css < docs/rollback/v1.75.0-styles.css.patch`, the same for `AGENTS.md`, `CLAUDE.md`, `README.md` and `scripts/check-release.js` with their `v1.75.0-<file>.patch`.
- After any rollback raise the version, update `CHANGELOG.md` and `TODO.md`, run `node scripts/build-all.js` and `node scripts/check-release.js`. A rollback of `check-release.js` and `AGENTS.md` brings back a site that allows github.io, only do it on purpose.
