# Rollback of v1.70.0

Owner request: every Unslop change (AGENTS.md rule 30) keeps a way back. This file lists what changed in `assets/styles.css` in v1.70.0 and how to undo it. Only `assets/styles.css` and the version stamps changed.

## How to go back
- Whole file: copy `docs/rollback/styles.css.v1.69.0` over `assets/styles.css` (it is the exact v1.69.0 file).
- By patch: in the site folder run `patch -R assets/styles.css < docs/rollback/v1.70.0-styles.css.patch` (reverses every change below).
- By item: use the table, the old value is in the second column. Then raise the version, update `CHANGELOG.md` and `TODO.md` and run `node scripts/check-release.js`.
- Or keep the archive `Ledgertone v1.69.0.zip` the owner already has and copy its `assets/styles.css` back.

## What changed (item, old, new)
| Unslop item | Old | New |
| --- | --- | --- |
| Gradient text | `h1 .soft` had `background:var(--hg)` with background-clip text and transparent fill; `--hg` was defined in the three token blocks (light violet to orange, dark white to grey) | `h1 .soft` is the plain `--muted` color; `--hg` removed |
| Uppercase tracked labels | `.status`, `.picker span`, `.meta`, `.tbl th`, `table.doc td::before`, `.more .mh`, `.stat .k`, `.prof ul.chips li`: uppercase, letter-spacing .08em (chips .1em) | sentence case, letter-spacing 0 |
| Small label sizes | `.stat .k` .6875rem; phone table headers `.tbl th.c-st` .5625rem (.03em) and `.tbl.hist th` .5625rem (.05em); chips weight 600 | .75rem; both .6875rem (11px) with letter-spacing 0; chips weight 500 |
| Weights | h1, `h1.gh .gn`, h2, `.method dt` 700; `.rk` 700; `.mdl` 700; `.btn`, `.text`, `.nm`, `.cbtn`, `.stat .v` 650 | h1, `.gn`, h2, `.method dt`, `.rk`, `.mdl` 600; `.btn`, `.text`, `.nm`, `.cbtn`, `.stat .v` 500 |
