# Rollback of v1.74.0

Motion pass: CSS and JS durations moved to the skill list, one easing curve in the JS fallback. Changed: `assets/styles.css`, `assets/app.js`, version stamps. `assets/motion.js` (springs) is untouched.

## How to go back
- Whole files: copy `docs/rollback/styles.css.v1.73.0` over `assets/styles.css` and `app.js.v1.73.0` over `assets/app.js`.
- By patch: in the site folder run `patch -R assets/styles.css < docs/rollback/v1.74.0-styles.css.patch` and `patch -R assets/app.js < docs/rollback/v1.74.0-app.js.patch`.
- After any rollback raise the version, update `CHANGELOG.md` and `TODO.md`, run `node scripts/build-all.js` and `node scripts/check-release.js`.

Not changed: `.sl`, `.nt`, `draw` and `pop` (the staff drawing; no page uses them), the spinner (`spin .8s linear infinite`), `assets/motion.js`.
