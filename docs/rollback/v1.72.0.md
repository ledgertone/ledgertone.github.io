# Rollback of v1.72.0

Second Unslop pass (spacing, copy, one easing curve, gray search clear button). Changed: `assets/styles.css`, `assets/app.js`, `index.html` (and `all.html`, generated from it), version stamps.

## How to go back
- Whole files: copy `docs/rollback/styles.css.v1.71.0` over `assets/styles.css`, `app.js.v1.71.0` over `assets/app.js`, `index.html.v1.71.0` over `index.html`, then run `node scripts/build-all.js` (rebuilds `all.html`).
- By patch: in the site folder run `patch -R assets/styles.css < docs/rollback/v1.72.0-styles.css.patch`, `patch -R assets/app.js < docs/rollback/v1.72.0-app.js.patch`, `patch -R index.html < docs/rollback/v1.72.0-index.html.patch`, then `node scripts/build-all.js`.
- Further back: `v1.71.0.md`, `v1.70.0.md` and their copies. After any rollback raise the version, update `CHANGELOG.md` and `TODO.md`, run `node scripts/check-release.js`.

## What changed
1. Spacing on the 4px grid: every `margin`, `padding` and `gap` value in px that was off the scale in `assets/styles.css` is rounded to the nearest step (ties up): 3,5 to 4; 6,7,9 to 8; 10,11,13 to 12; 14,15,17 to 16; 18 to 20; 22 to 24; 26 to 28; 30 to 32; 34 to 36 (139 values in 121 declarations, the full list is below). Not touched: heights and widths (hit areas of 44px and the phone control height of 33px, owner decision), `top`, `left`, `right`, `bottom`, negative values, values inside `calc`, `env`, `var`, `clamp`, the pills `.dn` and `.up`, the ripple `.tbl .rl i`.
2. Copy: the search field placeholder "Search artists" is now "Search" (the field has `aria-label="Search artists"`); the empty state "No artists match your search." is now "No artists match your search" (no period on a short string).
3. One easing curve: new token `--ease: cubic-bezier(.2,.8,.2,1)` in `:root`; the `ease-out` of the press and ping transitions and the curves of `.sl` and `.nt` use `var(--ease)`.
4. The clear button of the search field (native blue cross) is gray: `.search input::-webkit-search-cancel-button{filter:grayscale(1)}` at the end of `assets/styles.css`.
